# Tredence FDE Track 1 — Three Guided Capstones

1. Healthcare: provenance, privacy, conflicting/outdated evidence and abstention.
2. Retail/SCM: current structured state vs historical RAG, freshness, caching and A2A failure.
3. Financial services: policy versioning, hybrid retrieval, authorization-aware context/cache and human decision boundaries.

Participants submit code plus completed engineering decisions. Different architectures are acceptable when justified and evaluated.
