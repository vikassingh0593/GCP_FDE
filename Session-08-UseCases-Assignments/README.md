# Tredence FDE — Production RAG Architecture Challenges

Four ~60-minute architecture exercises followed by a maximum two-hour demonstrator. All cases assume participants can reuse the previous Google-native RAG implementation.

## Files

| # | Case | Core Pressure |
|---|---|---|
| 01 | MedEvidence | heterogeneous parsing, regulatory versioning, chunking/overlap |
| 02 | ForgeAssist | multimodal manuals, exact identifiers, safety, latency/offline |
| 03 | RMIntelligence | entitlement-aware retrieval, contracts, structured + RAG |
| 04 | OpsCommander | static + live evidence, freshness, latency, action authority |

Each assignment is organized into approximately **15 decision points**, ending in a crystal-clear two-hour build challenge and FDE defense.
