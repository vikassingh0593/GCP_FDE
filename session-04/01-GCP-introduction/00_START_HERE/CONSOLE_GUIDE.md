# Console Guide — for participants new to GCP

## Cloud Shell
Open Google Cloud Console and click **Activate Cloud Shell** (`>_`) in the top-right.

## Cloud Storage
Navigation menu → **Cloud Storage → Buckets**.  
After Step 3 you should see `ai-class-rag-h1`.

## BigQuery
Navigation menu → **BigQuery**. In Explorer expand:
`tredence-learning` → `fde_rag_h1`.

Use **+ Compose new query** to paste/run SQL if you prefer the console instead of `bq query`.

## Vertex / APIs
Navigation menu → **APIs & Services → Enabled APIs & services** to verify APIs.

## Important
Do not create random resources from the UI if a step already provides a command. The lab uses deterministic names so trainer and participant screens match.
