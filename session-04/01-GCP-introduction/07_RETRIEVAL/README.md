# Retrieval experiment

Run the same evidence needs through different retrieval behaviors.

1. `01_lexical_exact.sql` — proves exact clause retrieval.
2. `02_semantic.sql` — proves paraphrase/concept retrieval.
3. `03_hybrid.sql` — combines semantic + lexical signals.
4. `04_metadata_authority.sql` — demonstrates that retrieval relevance and source authority are different concerns.

Capture the Top-K. Do not judge by answer fluency yet.
